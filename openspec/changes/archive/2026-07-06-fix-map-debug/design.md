## Context

Карта (`MapCamera.ts`) использует Pointer Events для drag-to-pan. Баг: `pointerDown` инициализирован как `{x:0, y:0}`, поэтому первый же `pointermove` (без `pointerdown`) сравнивает координаты мыши с (0,0), превышает порог в 5px и включает `isPanning`. Карта двигается без нажатия кнопки.

Debug-флаг работает поюнитно: требует выделения юнита, `toggleDebug(unitId)` отправляет в воркер `set-unit-debug` для конкретного юнита.

## Goals / Non-Goals

**Goals:**
- Устранить ложное перетаскивание карты без нажатой кнопки
- Сделать debug-флаг глобальным (вкл/выкл для всех юнитов сразу)
- Убрать привязку debug к selectedUnitId

**Non-Goals:**
- Не менять архитектуру ввода/камеры
- Не добавлять новый UI

## Decisions

1. **PointerDown → null** вместо `{x:0, y:0}`. `handlePointerMove` проверяет `this.pointerDown` — если null, движение игнорируется. `handlePointerUp` сбрасывает в null. Это минимальное изменение с гарантией, что drag начинается только после реального `pointerdown`.

2. **Глобальный toggleDebug** без аргумента. При вызове проверяет, есть ли хоть один юнит с debug=true, и инвертирует для всех. Так чекбокс работает как общий включатель.

3. **`selectedDebug` → `debugOn`** в `StatusPanel.vue`. Просто проверяет `units.some(u => u.debug)` — не зависит от выбранного юнита.

## Risks / Trade-offs

- [Глобальный debug] При большом количестве юнитов отправляется N сообщений в воркер. Некритично — сообщения легковесны.
- [Глобальный debug] Нельзя включить debug для одного юнита. Для отладки этого достаточно, усложнение не требуется.
