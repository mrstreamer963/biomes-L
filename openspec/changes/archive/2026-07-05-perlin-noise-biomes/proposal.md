## Why

Текущая генерация биомов использует LCG (линейный конгруэнтный генератор), что даёт белый шум — каждая клетка выбирает биом случайно и независимо от соседей. В результате карта лишена пространственной связности: биомы хаотично разбросаны, нет узнаваемых зон (лесной массив, горная гряда, озеро). Это делает карту неестественной и непригодной для геймплея, где важны регионы и границы биомов.

Perlin noise даёт плавные, пространственно-когерентные значения, которые можно интерпретировать как карты высот, температуры и влажности — и на их основе назначать биомы, создавая реалистичные ландшафты.

## What Changes

- **Добавить генерацию Perlin noise (FBM)** в Rust-движок — заменить LCG-функцию `biome_id_from_lcg_value` на шумовую функцию, которая для координат `(x, y)` возвращает значение шума с учётом соседних клеток.
- **Расширить API `create_grid`** — добавить параметры генерации: масштаб шума (`scale`), тип шума (`noise_type`), количество октав (`octaves`), seed для детерминизма.
- **Multi-noise-подход** — использовать два/три слоя шума (например, температура + влажность) для определения биома по пороговой таблице, вместо одного случайного числа.
- **Настроить дефолтные параметры** на JS-стороне и передавать их в WASM при создании карты.
- **Сохранить полную детерминированность**: одинаковый seed → одинаковая карта.
- **Обратная совместимость**: API `grid_snapshot` и `cell_at` не меняются — меняется только внутренняя логика генерации.

## Capabilities

### New Capabilities

- `perlin-noise-generation`: Генерация биомов на основе многослойного Perlin-шума (FBM) с настраиваемыми параметрами (seed, scale, octaves, noise layers). Включает реализацию noise-функций на Rust, интеграцию с ECS-генерацией и JS-конфигурацию параметров.

### Modified Capabilities

- `biome-grid`: Requirement "Детерминированная генерация карты из seed" — способ генерации меняется с LCG на Perlin noise. Requirement "WASM API для создания и получения сетки" — `create_grid` получает дополнительные параметры (scale, octaves).
- `ecs-engine`: Requirement "Генерация карты через системы" — система генерации использует Perlin noise вместо LCG для назначения BiomeId.

## Impact

- **engine/Cargo.toml**: добавление зависимости `noise` или самописной реализации Perlin noise
- **engine/src/ecs/mod.rs**: замена `biome_id_from_lcg_value` на `biome_id_from_noise` с multi-noise-логикой
- **engine/src/wasm_api.rs**: расширение `create_grid` новыми параметрами, возможно новый тип `GenerationParams`
- **engine/src/rng.rs**: без изменений (LCG остаётся для других целей)
- **src/bridge/wasm.ts**, **src/worker/game.worker.ts**: передача параметров генерации в WASM
- **src/config/biomeConfig.ts**: возможно добавление пороговых значений для маппинга noise→biome
- **openspec/specs/biome-grid/spec.md**: обновление требований для новой сигнатуры create_grid
